# CEO UX 반려 기준 — 실데이터에서 추출한 7원칙

> **출처**: PowerTerminal 개발 전 과정 (v1.9.53→1.9.94, 2026-07-09~07-12) — CEO 요청기록 197건 + 커밋 48개 분석.
> ClassCare(강사/학생앱)·카페24 스킨 요청에서도 같은 패턴 반복 확인 — 프로젝트 불문 CEO의 일관된 감각.
>
> **성격**: "이렇게 디자인하라"는 규칙이 아니라 **"이걸 어기면 CEO가 반려한다"는 기준 목록**.
> 방향·창의성은 자유. 단, 화면을 내기 전에 이 목록으로 셀프 리뷰하고 어긴 항목이 있으면 스스로 고쳐서 내라.
> 목적: 기능 1 : UX 다듬기 5~9 라운드(실측 — 마인드맵 1:8, 메모장 1:9)로 늘어지는 수정 꼬리를 첫 설계에서 자르는 것.

---

## 1. 상태는 눈으로 — 사용자가 추측하면 반려

가장 빈도 높은 반려 사유 (전체 UX 요청의 ~25%).

- 모든 상태(진행중/완료/선택됨/접힘/펼침/조절가능/전송됨)는 **색·아이콘으로 상시 표시**.
- 실례: 작업중 세션 = 밝은 하늘 테두리+글로우, 완료 = 초록, 접힘/펼침 = ▲▼ 삼각형, "크기조절 가능한지 표시를 해줘야 해"(경계선에 세로 그립 표시), 선택된 요소는 주황 테두리.
- 확인 질문: *"이 화면만 보고 지금 무슨 일이 벌어지는지 알 수 있나?"*

## 2. 흐름이 끊기면 반려 — 다음 동작이 손에서 이어져야 한다

- 한 작업이 끝난 순간, **다음 확률 높은 동작이 키 하나 또는 클릭 0회**로 이어져야 함.
- 실례: 가지 생성→이름편집 자동 열림(전체선택)→Tab 확정→선택 유지→`+`로 다음 가지. 메모 Enter=저장. 전송 후 입력란 자동 클리어+포커스 유지.
- 따라오는 UI(버튼·핸들·연결선)는 **조작과 동시에** 움직여야 함 — "이동 끝나고 뿅 나타나기" = 즉시 반려.

## 3. 화면 흔들림 = 반려 — 상태가 바뀌어도 레이아웃 고정

- 테두리·배지·패널이 생길 때 **이웃 요소의 크기·위치를 밀면 안 됨**.
- 해법 패턴: 테두리 강조는 `outline`(레이아웃 비점유), 사이드 패널은 `absolute` 오버레이, 입력칸은 "항상 한 줄" 같은 고정 제약.
- 실례: "테두리가 생겨도 안흔들리게", "요청내역을 absolute로 하면 되지않아?"(터미널 폭 유지).

## 4. 같은 일 하는 버튼 2개 = 반려 — 라벨은 상황이 정한다

- 버튼 추가 전에 **기존 버튼이 상황 인지형으로 겸할 수 있는지** 먼저 검토 (예: 선택 없으면 '뿌리추가', 선택 있으면 '가지').
- 텍스트 라벨 최소화 — 아이콘+툴팁 우선 ('+세션추가'→'+세션', 'QR' 글자 삭제).
- 안 쓰는 버튼은 과감히 숨김/삭제. "있으면 좋은" 요소는 빼고 시작 (기존 금기와 동일 방향).

## 5. 밀도는 hover로 — 평소엔 숨기고 필요할 때만

- 행(row) 단위 액션 버튼(삭제·복사·이동)은 **hover 시 노출이 기본**, 터치 기기는 `@media (hover: none)`으로 상시 노출.
- 단, 그 화면의 **주 동작 1개**(전송 등)는 항상 보임.
- 부가 정보(AI 메모·설명)도 hover 노출 — 화면 기본 상태는 깨끗하게.

## 6. 모바일은 축소판이 아니라 재설계 — 엄지 기준

- PC 완성 후 모바일은 **터치 목표 크기·스크롤·고정 헤더를 다시 설계**.
- CEO가 기기별로 다른 배율을 지시함: 전송버튼 폰 2배/PC 1.5배, 폰 터미널 높이 1.5배, 닫기버튼은 모서리 1/4 걸친 빨간 원형 X.
- 세로로 쌓이는 다단 레이아웃은 아코디언(제목 탭→그것만 펼침) 검토.

## 7. 누르는 맛 — 마이크로 피드백은 장식이 아니라 기능

- 클릭 가능한 모든 것에 눌린 반응(`:active` 어둡게, 팡 효과, 폰은 짧은 진동).
- 창 열닫·이동은 **0.15~0.2초 애니메이션** — 그보다 길면 "느리다"고 반려.
- 스크롤 점프는 즉시 점프 대신 부드럽게 (단 0.7초 상한).

---

## 보조 기준 2개

- **파괴적 동작은 확인 1회, 단 한 번만** — 삭제·하위포함 삭제는 confirm 1번. 이중 확인은 반려.
- **데이터는 퍼갈 수 있어야** — 목록·기록 화면엔 복사 버튼(개별+전체), 내보내기(엑셀/PNG)를 기본 검토. 내보내기 파일명·헤더는 영어.

## 셀프 체크 (화면 내기 전 7초)

```
[ ] 상태가 전부 눈에 보이나?           (원칙 1)
[ ] 작업 후 다음 동작이 이어지나?       (원칙 2)
[ ] 상태 변화에 레이아웃이 흔들리나?    (원칙 3)
[ ] 겸할 수 있는 버튼을 새로 만들었나?  (원칙 4)
[ ] 행 액션이 상시 노출로 어지럽나?     (원칙 5)
[ ] 모바일 터치 목표·스크롤 따로 봤나?  (원칙 6)
[ ] 누르는 맛·열닫 애니 있나?          (원칙 7)
```
